     recreate BPPV symptoms."; "Most cases of BPPV can be managed with treatment maneuvers by a physical therapist."

     been found to cure BPPV, and that symptoms return for about half of people within three years. It does not name
     the Dix-Hallpike test or the Epley maneuver: name them only if you fetch a source that does.
